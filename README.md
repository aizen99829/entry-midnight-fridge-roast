# Midnight Fridge Roast

SPDX-License-Identifier: MIT

A one-line roast of the fridge at 3 AM, entered in the make.fun bounty
[Midnight Fridge Roast](https://make.fun/bounty/u-carbon-forge-midnight-fridge-roast-fc5d44a7).

## The line

> My fridge hums at 3 AM like a server that never sleeps -- except its only uptime is judging me for eating cold pizza standing in the dark.

The joke treats the fridge as a tiny data center: always on, always lit,
always watching. Its one real workload is not cooling food, it is silently
judging the human who raids it in the dark.

## How it works

`main.py` holds the single roast line, checks that it is exactly one line
and no longer than 200 characters, prints it, and writes it to
`/output/entry.txt` for grading.

```sh
python3 main.py
```
